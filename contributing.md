# Beitragen

Vielen Dank für Ihren Beitrag.

Befolgen Sie diese Richtlinien, wenn Sie zu diesem Projekt beitragen.

## Verhaltenskodex

Dieses Projekt folgt dem Adobe [Verhaltenskodex](code-of-conduct.md). Durch die Teilnahme
Sie erklären sich damit einverstanden, diesen Kodex aufrechtzuerhalten. Inakzeptables Verhalten melden an
[Grp-opensourceoffice@adobe.com](mailto:Grp-opensourceoffice@adobe.com).

## Handbuch für Mitwirkende

Siehe das [Handbuch für Mitwirkende an Adobe-Dokumenten](https://experienceleague.adobe.com/en/docs/contributor/contributor-guide/introduction).

## Frage stellen

Zur Beantwortung einer Frage ein Problem einreichen Projektverantwortliche besprechen die Projektausrichtung
und Lösungsvorschläge in Problem-Threads.

## Lizenzvereinbarung für Mitarbeiter

Alle Beiträge von Drittanbietern erfordern eine unterzeichnete Lizenzvereinbarung für Mitwirkende (Contributor License Agreement, CLA).
Die Vereinbarung gibt Adobe die Erlaubnis, Ihre Beiträge als Teil zu verteilen
des Projekts. [Unterschreiben Sie die ](https://opensource.adobe.com/cla.html). Sie müssen
Senden Sie die Adobe-CLA nur einmal.

## Code-Überprüfungen

Übermitteln Sie Änderungen als Pull-Anforderungen. Projektverantwortliche überprüfen jede Pull-Anfrage.
Weitere Informationen finden Sie unter [Über Pull-Anfragen](https://help.github.com/de/articles/about-pull-requests/).

## Werden Sie Verantwortlicher

Verantwortliche haben vollen Schreibzugriff und helfen beim Durchführen des Projekts. Vorhandene Verantwortliche
Verwenden Sie einen internen Nominierungsprozess und müssen Sie einen Konsens erreichen, bevor sie
Einen neuen Verantwortlichen einladen. Kontaktieren Sie einen vorhandenen Verantwortlichen, wenn Sie mehr werden möchten
Beteiligte.

## Sicherheitsprobleme

Sicherheitsprobleme nicht in diesem Problem-Tracker melden. Stattdessen ([ Adobe-Sicherheit kontaktieren](https://helpx.adobe.com/de/security/alertus.html).
